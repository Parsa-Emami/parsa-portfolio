# Security Policy

## Supported version

Only the latest commit deployed from the `main` branch is supported.

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Send a private report to the portfolio owner using the email configured in the
production environment. Include:

- the affected URL or component;
- reproducible steps;
- impact and supporting evidence;
- any suggested remediation.

Secrets, credentials, personal data, or exploit payloads must not be posted in
public issues or pull requests.
